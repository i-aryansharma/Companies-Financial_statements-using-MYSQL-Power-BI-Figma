# 📊 Financial Statement Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Financial Statement Analysis Dashboard** built in **Power BI** to analyze the financial performance of multiple companies.
The dashboard provides insights into revenue, profitability, financial trends, and key performance indicators (KPIs), enabling users to evaluate business performance through interactive visualizations and slicers.

---

## 🎯 Project Objectives

- Analyze company financial performance.
- Monitor revenue and profit trends over time.
- Compare profitability across companies.
- Identify top-performing months based on revenue.
- Build an interactive dashboard for business decision-making.
